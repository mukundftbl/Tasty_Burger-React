# 🍔 Burger Online Ordering Website

A modern and responsive **Burger Online Ordering Website** built with React.js.  
The project provides a smooth food-ordering experience where users can browse burgers, add items to a cart, manage their order, and proceed through the checkout interface.

The website is completely **frontend-based** and is designed to work smoothly across **mobile, tablet, laptop, and desktop devices**.

## 📌 About The Project

This project is a frontend burger ordering application created using **React.js**.

The main goal of the project was to build a realistic food-ordering interface with reusable React components, responsive layouts, cart functionality, and a smooth user experience.

Users can browse the available burgers, select products, add them to their cart, update quantities, and proceed to checkout.

---

## ✨ Features

### 🍔 Food Ordering

- Browse burger products
- View burger details
- Add burgers to cart
- Remove items from cart
- Increase/decrease product quantity
- View total cart amount
- Order summary
- Checkout interface

### 🛒 Shopping Cart

- Add products to cart
- Update item quantities
- Remove products
- Automatically calculate total price
- Cart state management using React Context API

### 🎨 User Interface

- Modern burger/food ordering design
- Clean navigation
- Responsive layout
- Interactive buttons and components
- User-friendly ordering flow

### 📱 Responsive Design

The website is optimized for:

- 📱 Mobile phones
- 📟 Tablets
- 💻 Laptops
- 🖥️ Desktop computers

The layout automatically adapts to different screen sizes.
